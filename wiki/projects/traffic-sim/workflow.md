# Стек симуляции: роли и потоки данных

> Стек: **MATSim → SUMO → WeBots**

---

## 1. MATSim — стратегический уровень (спрос)

**Задача:** смоделировать *поведение населения* — откуда, куда и когда люди едут в течение суток.

MATSim — агентная модель: каждый житель города (агент) имеет суточный план: дом → работа → магазин → дом. Агенты итеративно оптимизируют маршруты и время поездок до равновесия. На выходе — реалистичное распределение транспортного спроса по всему городу.

Применяется для:
- генерации O-D матриц (откуда-куда) по часам суток
- сценарного анализа: что будет если закрыть мост, добавить полосу
- калибровки спроса по данным переписи, опросов, парковок
- планирования эвакуации (суточный план поведения населения)

---

## 2. SUMO — сетевой уровень (движение)

**Задача:** смоделировать *физическое движение транспорта* по дорожной сети.

SUMO знает про каждый автомобиль: скорость, ускорение, смену полосы, следование за лидером (модели Krauss, IDM). Управляет светофорами, маршрутами ОТ, пешеходами, велосипедистами. TraCI API позволяет управлять симуляцией из Python в реальном времени.

Применяется для:
- микроскопической симуляции всей дорожной сети города
- расчёта метрик: пробки, время в пути, очереди, загрузка перекрёстков
- управления светофорами (адаптивные алгоритмы через TraCI)
- экспорта траекторий ТС для 3D визуализации

---

## 3. WeBots — микроуровень (3D визуализация и ИИ)

**Задача:** создать *физически точную 3D среду* для одного перекрёстка или участка улицы.

WeBots — симулятор физики с реальными сенсорами (LiDAR, камера, GPS). Используется там, где важна точная 3D геометрия: обучение RL-агентов, тестирование автопилотов, визуализация для демо. Через `SumoInterface` PROTO получает из SUMO позиции и скорости ТС и рендерит их в 3D.

Применяется для:
- 3D визуализации трафика на выбранном перекрёстке
- обучения RL-агентов (управление светофором, поведение водителя)
- тестирования сенсоров беспилотных ТС
- демо-презентаций на хакатонах

---

## 4. MATSim → SUMO

**Передаётся: файл маршрутов** (`.rou.xml` или `.trips.xml`)

MATSim генерирует планы агентов — конкретные маршруты с временны́ми метками. Эти данные конвертируются в формат SUMO:

```
MATSim output:          →    SUMO input:
plans.xml                    routes.rou.xml
(агент A: 08:00             (vehicle A departs 28800s,
 дом→работа через           route: edge1 edge2 edge3)
 ул. Ленина)
```

Инструмент конвертации: `matsim2sumo` (Java/Python коннектор).

**Без MATSim:** для одной улицы достаточно `randomTrips.py` или `activitygen`. MATSim нужен когда важен **реалистичный суточный спрос** на уровне всего города, а не случайные поездки.

---

## 5. MATSim → WeBots

**Напрямую — ничего.**

MATSim работает на макроуровне и не производит данные пригодные для 3D. Связь косвенная: MATSim → SUMO → WeBots (через SUMO).

Теоретически можно передать O-D матрицу для настройки интенсивности потока в WeBots, но на практике это избыточно — WeBots получает всё нужное из SUMO.

---

## 6. SUMO → WeBots

**Передаётся в реальном времени через TraCI / `SumoInterface`:**

| Данные | Что получает WeBots |
|---|---|
| Позиция каждого ТС (x, y) | Координаты для рендеринга в 3D |
| Скорость ТС | Анимация движения |
| Угол поворота | Ориентация модели автомобиля |
| Тип ТС (car, bus, truck) | Выбор 3D модели |
| Состояние светофора (G/Y/R) | Цвет светофора в 3D |
| Позиции пешеходов | 3D модели пешеходов |

**Механизм:** WeBots `SumoInterface` PROTO подключается к SUMO TraCI-серверу. На каждом шаге симуляции WeBots запрашивает состояние окружающих ТС (в радиусе `radius` метров) и обновляет их 3D модели.

```
SUMO (TraCI server :8813)
        ↑↓ каждый simulation step
WeBots (SumoInterface PROTO)
  → рендерит ТС в радиусе 200м от камеры
  → max 100 ТС одновременно (ограничение WeBots)
```

---

## Схема потоков данных

```
            планы агентов             маршруты + временные метки
MATSim ──────────────────────────────────────────▶ SUMO
(суточный спрос,                                    │
 O-D матрицы)                                       │ TraCI: позиции ТС,
                                                    │ скорости, светофоры
                                                    ▼
                                                 WeBots
                                            (3D рендеринг перекрёстка,
                                             RL-агенты, сенсоры)
```
